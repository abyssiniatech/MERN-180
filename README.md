# 🚀 MERN + Next.js Full-Stack Developer Roadmap (180 Days)

A **professional, structured, and practical 6-month full-stack web development course** using:

- **MongoDB**
- **Express.js**
- **React.js**
- **Node.js**
- **Next.js**

Designed to make you **job-ready, freelance-ready, and production-ready**.

# 📅 180-Day Learning Plan

## ✅ Phase 1: Web Fundamentals (Days 1–30)

### Week 1 – HTML Basics
- HTML structure, tags, attributes
- Semantic HTML

📚 Resources:
- https://developer.mozilla.org/en-US/docs/Web/HTML
- https://www.w3schools.com/html/

### Week 2 – CSS Basics
- Selectors, Box Model, Flexbox, Grid

📚 Resources:
- https://developer.mozilla.org/en-US/docs/Web/CSS
- https://css-tricks.com/

### Week 3 – JavaScript Basics
- Variables, functions, loops, arrays

📚 Resources:
- https://javascript.info
- https://developer.mozilla.org/en-US/docs/Web/JavaScript

### Week 4 – DOM Manipulation
- Events, forms, validation

✅ Project:
- Build a **Portfolio Website**

---

## ✅ Phase 2: Advanced JavaScript (Days 31–60)

### Week 5
- ES6+ (arrow functions, destructuring, modules)

### Week 6
- Asynchronous JS (Promises, async/await, fetch)

### Week 7
- Error handling, localStorage, sessionStorage

### Week 8
- Mini Projects:
  - Todo App
  - Weather App (API)

📚 Resources:
- https://javascript.info/async
- https://jsonplaceholder.typicode.com

---

## ✅ Phase 3: React.js (Days 61–100)

### Week 9–10
- React components, JSX
- Props & state

### Week 11–12
- Hooks (useState, useEffect, useRef, useContext)

### Week 13–14
- React Router
- Forms with validation

✅ Projects:
- Blog App
- Student Management App

📚 Resources:
- https://react.dev
- https://beta.reactjs.org

---

## ✅ Phase 4: Backend with Node.js + Express (Days 101–130)

### Week 15–16
- Node.js fundamentals
- Express.js routing

### Week 17–18
- REST APIs
- Authentication (JWT)

### Week 19
- Handling file uploads

✅ Projects:
- REST API for Blog App
- Authentication System

📚 Resources:
- https://nodejs.org/en/docs
- https://expressjs.com

---

## ✅ Phase 5: MongoDB (Days 131–150)

### Week 20–21

- Mongoose ODM

- Connecting MongoDB with Express

✅ Project:
- Full CRUD App

📚 Resources:
- https://www.mongodb.com/docs
