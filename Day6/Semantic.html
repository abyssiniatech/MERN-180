Understanding Semantic HTML

Section 1: Introduction to Semantic Tags

Semantic tags provide meaning to the web page structure, making it easier for both developers and browsers to understand the content.

Section 2: Common Semantic Tags

  • <header> - Defines a header for a document or section
  • <nav> - Defines navigation links
  • <main> - Specifies the main content of a document
  • <section> - Defines sections in a document
  • <article> - Represents an independent piece of content
  • <footer> - Defines a footer for a document or section

Did You Know?

Using semantic tags improves accessibility and SEO for web pages.
